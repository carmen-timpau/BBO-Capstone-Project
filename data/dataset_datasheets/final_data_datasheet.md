**Dataset Description:** BBO Capstone Final Datasets obtained for all 8 Black-Box Functions

<br>


**Motivation:**

This dataset was created to store all collected data over the 13 weeks of the BBO Capstone Project. This project represents my work as a participant in the Black-Box Optimisation Challenge hosted by Imperial College London Executive Education, as part of their 6-month Professional Certificate in Machine Learning and Artificial Intelligence joint programme, which took place between February – September 2026. The overarching aim of this project was to develop ML algorithms in Python that maximise the 8 expensive-to-query black-box functions.

<br>


**Composition:**  

This is now a static dataset saved as a .pkl file, which stores the full final datasets for all 8 unknown objective functions constructed during the 13 weeks of the Black-Box Optimisation Challenge. This includes all initial datasets provided at the beginning of the challenge, as well as all new datapoints collected over the course of the 13 weeks of the BBO capstone project _via_ Bayesian Optimisation.

**Collection Process:**

The datasets within this .pkl file have been constructed gradually between June - August 2026, over the 13 weeks of the Bayesian Optimisation development process, as part of the Black-Box Optimisation Challenge.

The latest queries (1 query per function <=> the last datapoint in each function’s dataset stored within this .pkl file) were generated by executing the [Main Execution Script: BBO Capstone Project Week 13 - Full Machine Learning Pipeline](https://github.com/carmen-timpau/BBO-Capstone-Project/blob/main/experiments/week_13/main.py). After all expensive black-box functions have been executed with the inputs predicted in Week 13 by the Bayesian Optimisation pipeline mentioned above, and their outputs have been obtained, the resulting new datapoints have been immediately appended to the previous weekly dataset [wk13_input_data.pkl](https://github.com/carmen-timpau/BBO-Capstone-Project/blob/main/experiments/week_13/wk13_input_data.pkl) to generate this final dataset, [final_data.pkl](https://github.com/carmen-timpau/BBO-Capstone-Project/blob/main/experiments/week_13/diagnostics_results/final_data.pkl).
A technical summary of the specific Bayesian Optimisation ML pipeline deployed to generate the latest set of points within this dataset (1 per function), can be found in [BBO Week 13 - Bayesian Optimisation Strategy Summary](https://github.com/carmen-timpau/BBO-Capstone-Project/blob/main/experiments/week_13/strategy_summary.md).

<br>


**Preprocessing and Uses:**

No preprocessing transformations have been applied to the contents of this dataset. This dataset contains the raw data which was directly provided by Imperial College London. The data was obtained by querying the 8 black-box functions investigated in this project, at the respective high-dimensional input points to obtain their true output values and aid in Bayesian Optimisation pipeline developments as part of this BBO capstone project.

As this is a static dataset now that the BBO capstone project has ended (September 2026), the intended further use of this dataset is only for reflection on the final Bayesian Optimisation strategy employed and concluding on the overall project. 
This dataset is inappropriate for use in any other projects, or in any other ways other the one stated above, as it is strictly relevant for these specific black-box functions investigated within this project.
